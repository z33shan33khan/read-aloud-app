CHROME — BEST WAY TO GET PIPER / URDU VOICES

Edge already has good Urdu voices. Chrome usually does not. The easiest fix that keeps this interface is:

  1. Install the free extension Piper Text-to-Speech Voices
  2. Open the extension once and download the Urdu voices you want (e.g. Fasih, Aegis)
  3. Close the extension — you do not need its GUI for reading
  4. Return here → tap Refresh voice list above
  5. In Settings → Voice, select the new Piper voice and read with your own interface

The extension only registers Piper models with Chrome’s speech engine. After that, this Pro Reader can use them like any system voice. Your highlighting, speed, library and layout stay exactly as they are.

Other options (Windows system voices, Android, etc.)

Reading uses the voices installed on your device. Download a good language pack once, then select it in Settings → Voice.

Windows 11 (works well in Edge)
  1. Open Settings → Time & language → Language & region
  2. Click Add a language → search Urdu (prefer Pakistan)
  3. Tick Text-to-speech and install (you can leave display language unchanged)
  4. Optional: Settings → Time & language → Speech → Manage / Add voices
  5. Close and reopen this page, then choose the new ur voice in Settings
Android
  1. Install a dedicated Urdu TTS engine (recommended: Rehnuma Awaz from Play Store)
  2. Open device Settings → System → Languages & input → Text-to-speech
  3. Set the preferred engine to Rehnuma Awaz (or Google TTS with Urdu data)
  4. Download the Urdu voice data inside that engine if asked
  5. Return here, refresh voices, and select the Urdu voice
Other languages

Same idea: install the language’s Text-to-speech pack on Windows, or a good offline engine on Android (Google TTS language data, or a language-specific app). Then pick the matching voice in this app’s Settings.

After installing, use the “Refresh voice list” button above or reopen the page so the browser sees the new voices.
